# ⚡ Vocabulary Upgrade Studio (Repository 2 / Variety 2)

Automated video generator for **"Stop Saying VERY... Say THIS Instead!"** 9:16 Vertical Facebook Reels and Shorts.

## 🌟 Key Features
- **High Retention Reel Layout**: 1080x1920 vertical canvas tailored for Facebook Watch & Reels.
- **Visual Comparison**: Split Red "❌ BASIC / AVOID" vs Emerald Green "✅ NATIVE UPGRADE" cards.
- **Phonetics & Syllables**: Clear IPA phonetic pronunciation breakdown and syllable guide.
- **Spoken Walkthrough**: Explanatory voice track guiding the viewer through native usage context.
- **Facebook Viral Hook**: Engineered to generate high save rates and comment engagement.

## 🚀 How to Run
```bash
# 1. Generate vocabulary reel
python run_generator.py

# 2. Publish to Facebook Page
python publish_facebook.py output/run_XXXX/vocab_upgrade_reel.mp4 output/run_XXXX/metadata.json
```

## 📱 Recommended Facebook Page Target
- **Page Concept**: *Instant English Upgrade / Daily English Vocabulary*
- **Target Audience**: Mobile Facebook Reels viewers looking for quick, 30-second daily vocabulary improvements.
